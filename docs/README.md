## 1. 핵심 객체/기능

### 자동차

- 이름 (5자 이하)
- 전진 (엑셀)
- 멈추기 (브레이크)
- 전진하는 자동차의 출력에는 이름을 같이 출력 - 전진 조건

### 입력

- 자동차 이름 - 쉼표 구분자
- 이동 횟수
- 전진 조건 - 0-9 사이의 무작위 값이 4 이상인 경우
- 예외 발생시키고 종료

### 출력

1. 출력
   - 게임 완료 후 우승자 출력（다수）
   - 다수는 쉼표로 구분
   - 뭐 간단한데? 대신에 반복하면서 계속 상태를 출력하는 느낌이네. 불변 객체는 안 되겠다
   - `List<Car>`에 대한 래퍼 클래스를 만들고 얘한테도 이동 요청 메서드를 만들자
2. 출력 형식 `jun : ---`
   - 흠, 이걸 봐. 이제 저기 뒤에 `-` 문자가 계속 늘어나게 될거야
   - 매번 String을 생성하면 끔찍하겠다 그치?
   - `StringBuilder`에 repeat 같은 메서드가 있었던 것 같은데 함 찾아보자
   - 그리고 자동차 내부랑 List<Car> 클래스 두 개에 모두 StringBuilder가 있어야 할 것 같아
3. 아 추가로 우승자는 어떻게 계산해?
   - 솔직히 나이브하게 하면 최종적으로 한 번 쭉 순회하면 되는데
   - 매 시행의 결과는 항상 고정이잖아 그럼 낭비지
   - 시행마다 결과가 정적으로 유지되어야 해
4. 차가 이동하는 건 요청만 하면 랜덤하게 움직이는거네?
   - 근데 그러면 테스트하기 어려우니까 내부에서 함수를 래핑해서
   - 랜덤 생성 하나, 이동 하나로 나누자
   - 또 package-private 생성자를 만들어서 fixture를 손쉽게 만들 수 있도록 하자

## 2. 프로그램 제약 ([`InternalCause.java`](../src/main/java/racingcar/InternalCause.java))

1. 입력할 때， 일부러 공백을 앞 뒤에 넣는 경우가 있을까？
   - 사용자의 입력이 콘솔로 들어온다면， 뭐 어쩌다가 띄어쓰고 싶어서 `"A, B"` 이렇게 입력할 수도 있잖아？
   - 우리가 보통 입력에 공백을 명시적으로 넣지는 않으니까
   - 적어도 쉼표를 사이로 들어오는 공백은 `"A,B"` 나 `"A, B"` 모두 같은 방식으로 처리되도록 하자
   - 또 이름이 비어있는 것도 이상하잖아. 그치? 비어있는 건 안 된다고 하자
2. 이름이 ５자만 가능하다고？ 메모리를 아끼려고 하는건가？
   - 근데 ５자면 생각보다 경우의 수가 좁긴 하네
   - 이거 게임인데 사용자 이름이 같아도 되는거야？
   - 당연히 확인해야 하는 거 아닌가？ 중복이 없도록 `Set`으로 확인하자
3. 이동은 당연히 정수여야만 하겠지?
   - 그리고 음수가 들어오면 안 될거야. 그러니까 자연수 검사를 해야하고
   - 솔직히 들어오는 값의 제한은 어차피 이거 횟수를 출력해야하는데 적당히 제한하자
   - 입력은 long으로 받되, 제한은 한 1만 정도?
   - 아 근데 진짜 변태처럼 계속 돌려볼 수도 있잖아. 그러니까 Integer.MAX_VALUE로 하자 그냥
4. 잘못된 입력에는 `IllegalArgumentException` 반환하고 프로그램 종료!
5. 아 추가로 출력에 이름 있잖아. 저거는 입력 순서대로 나오는 게 좋겠지?
   - 보면 그룹 출력이나, 우승자 출력 모두 기존 입력 순서가 유지되고 있어 참고해.

## 3. 가능한 입력 및 출력 케이스 ([`ApplicationTest.java`](../src/test/java/racingcar/ApplicationTest.java))

- 일단 출력을 세 가지로 나눠볼 수 있어
- 하나는 차의 정보, 둘은 차의 그룹의 정보, 셋은 우승자 정보
- 그룹의 정보는 그냥 차의 정보를 나열한 수준이야. 그래서 그냥 순서만 확인하면 돼

### 입력 (자동차 이름)

#### 자동차 이름 길이 예외 (5자 이하)

- "abcdef" -> 예외
- "" -> 예외
- null -> 예외
- "a," -> 예외
- "a,abcdef" -> 예외
- "a, abcdf" -> 가능
- "가나다라마" -> 가능
- "가나다라마바" -> 예외
- "a, 가나다라마" -> 가능
- "a,가나다라마바" -> 예외

### 입력 (시행 횟수)

- 실수 형식 -> 예외
- 음수 -> 예외
- Integer.MAX_VALUE 이상 -> 예외
- Long.MAX_VALUE 이상 -> 예외
- 0 -> 가능

### 출력 (경주 중)

```text
   pobi, 2,
   woni, 4,
   jun, 3
```

```text
pobi : --
woni : ----
jun : ---
```

### 출력 (우승자)

#### 단독 우승자 안내 문구

```text
   pobi, 4,
   woni, 3,
   jun, 3
```

`최종 우승자 : pobi`

#### 공동 우승자 안내 문구

```text
   pobi, 3,
   woni, 2,
   jun, 3,
```

`최종 우승자 : pobi, jun`
