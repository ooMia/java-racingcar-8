# [요구사항](./requirements.md) 분석

## 1. 핵심 객체/기능

### 자동차

- 이름 (5자 이하)
- 전진 (엑셀)
- 총 이동 거리

### 입력

- 자동차 이름 - 쉼표 구분자
- 이동 횟수
- 전진 조건 - 0-9 사이의 무작위 값이 4 이상인 경우
- 예외 발생시키고 프로그램 종료

### 출력

- 게임 완료 후 우승자 출력 (다수는 쉼표로 구분)
- `List<Car>`에 대한 래퍼 클래스를 만들고 얘한테도 이동 요청 메서드를 만들자

#### 자동차별 출력 형식 `jun : ---`

- `StringBuilder`에 repeat 같은 메서드가 있었던 것 같은데 함 찾아보자
- 출력에 필요한 상태를 클래스가 저장할 필요는 없을 것 같아. 그냥 필요할 때 만들어.

#### 우승자 계산

- 상태를 문자열로 저장하는 게 오히려 메모리 상으로 더 낭비 같아.
- 그냥 필요할 때 정렬해서 출력하자.

#### 자동차의 무작위 이동

- 테스트하기 어려우니까 내부에서 함수를 래핑해서 랜덤 생성과 이동을 분리하자
- 또 package-private 생성자를 만들어서 fixture를 손쉽게 만들 수 있도록 하자

## 2. 프로그램 제약 ([`CarProblem.java`](../src/main/java/racingcar/car/CarProblem.java))

### 입력 시 공백 처리

- 결과적으로 전달된 전체 이름이 하나도 없는 건 이상한 게 맞아.
- 하지만 그 외에는 그냥 쉼표 기준으로 자르기만 하고 진행하는 느낌으로 단순하게 가자
- 근데 아무리 생각해도 이름에 공백만 들어가는 경우는 콘솔 상으로 구분을 못하니까 허용하면 안 될 것 같아
- 공백을 포함해서 자르되, 그 결과 남은 결과가 적절하지 않으면 예외를 반환하도록 하자

### 이름 5자 이하

- 근데 5자면 생각보다 경우의 수가 좁긴 하네
- 이거 게임인데 사용자 이름이 같아도 되는거야？
- 당연히 확인해야 하는 거 아닌가？ 중복이 없도록 `Set`으로 확인하자
- 대소문자 구분은 애매하니까 패스
- 뭐 일단 바이트 수준에서는 다르니까 특별한 요구가 들어오기 전까지는 허용하자.

### 이동의 횟수는 0 이상의 정수

- 그리고 음수가 들어오면 안 될거야. 그러니까 자연수 검사를 해야하고
- 솔직히 들어오는 값의 제한은 어차피 이거 횟수를 문자열로 출력해야하는데 적당히 제한하자
- 입력은 long으로 받되, 상한은 Integer.MAX_VALUE

### 기타

- 잘못된 입력에는 `IllegalArgumentException` 반환하고 프로그램 종료!
- 출력의 이름은 입력 순서를 유지 (그룹 출력이나, 우승자 출력 모두 기존 입력 순서가 유지되고 있음)
- 라이브러리 래핑: 테스트 적용이나 구현체 변경 상황 고려

## 3. 가능한 입력 및 출력 케이스 ([`ApplicationTest.java`](../src/test/java/racingcar/ApplicationTest.java))

- 일단 출력을 세 가지로 나눠볼 수 있어
- 하나는 차의 정보, 둘은 차의 그룹의 정보, 셋은 우승자 정보
- 그룹의 정보는 그냥 차의 정보를 나열한 수준이야. 그래서 그냥 순서만 확인하면 돼

### 입력 (자동차 이름)

#### 자동차 이름 길이 예외 (5자 이하)

- "abcdef" -> 예외
- "" -> 예외
- null -> 예외
- "a," -> 예외
- "a,abcdef" -> 예외
- "a, abcdf" -> 가능
- "가나다라마" -> 가능
- "가나다라마바" -> 예외
- "a, 가나다라마" -> 가능
- "a,가나다라마바" -> 예외

### 입력 (시행 횟수)

- 실수 형식 -> 예외
- 음수 -> 예외
- 0 -> 가능
- Integer.MAX_VALUE -> 가능
- Integer.MAX_VALUE 초과 -> 예외
- Long.MAX_VALUE 이상 -> 예외

### 출력 (경주 중)

- `pobi, 2, woni, 4, jun, 3`

```text
pobi : --
woni : ----
jun : ---
```

### 출력 (우승자)

#### 단독 우승자 안내 문구

- `pobi, 4, woni, 3, jun, 3`

`최종 우승자 : pobi`

#### 공동 우승자 안내 문구

- `pobi, 3, woni, 2, jun, 3`

`최종 우승자 : pobi, jun`
